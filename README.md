# קבלה – שלחו לנו צ'אט, נחזיר לכם קבלה

מנוע סטטיסטיקה דטרמיניסטי שרץ בדפדפן, ועליו "השורה התחתונה" שכותב LLM, עם paywall של ₪15.

שם המוצר מוגדר ב-`lib/brand.ts`. הקול של הכתיבה מוגדר ב-`lib/report/prompt.ts`.

## הקונספט

צ'אט על הצ'אט. במקום טופס יש שיחה, ובמקום דוח יש קבלה.

- **Setup (8 שאלות):** שיחה עם המוצר. כל שאלה מגיעה כהודעה, והתשובה ניתנת בשלוש צורות: תשובות מהירות (קשר, מקור, מיקוד, שפה), שורת כתיבה (מייל וקוד), וסליידר (כמה ישיר). ההעלאה, איחוד הפרופילים ושינוי השמות קורים בתוך השיחה.
- **המספרים:** קבלה מפורטת אחת עם 7 פריטים שמודפסים אחד אחרי השני. לוח שנה בנקודות, מי כותב, זמנים, ברקוד שעות, הנאום הארוך, ההתחלה והסוף, וטביעת אצבע.
- **הדוח:** המשך הקבלה. כותרת, סעיף 1, ואז "המדפסת עצרה כאן" ו"לתשלום ₪15.00". אחרי תשלום: כל הסעיפים, פריט שקט, שורה לכל משתתף, והשורה התחתונה.
- **שפה עיצובית:** מונוכרום. רקע גרפיט, נייר קבלה לבן, Rubik לעברית ו-Space Mono למספרים, קווים מקווקווים ושוליים משוננים.

## הרצה

```bash
npm install
cp .env.example .env.local   # אופציונלי: ANTHROPIC_API_KEY, STRIPE_SECRET_KEY
npm run dev
```

בלי מפתחות הכול עובד במצב דמו: דוח דטרמיניסטי עם ציטוטים אמיתיים מהצ'אט, קוד ה-OTP מוצג על המסך, והתשלום מדומה. במצב production התשלום המדומה וקוד ה-OTP על המסך חסומים.

צ'אט לדוגמה: `python3 scripts/make-sample-chat.py sample.zip`

טסט ממוקד לפרסר ולמדדים: `npx vitest run lib/chat`

## מבנה

| נתיב | תפקיד |
|---|---|
| `lib/chat/parse.ts` | `parseWhatsApp()` – iPhone ו-Android, ניקוי U+200E/U+200F, סינון הודעות מערכת (U+202B, שם הקבוצה), שורות המשך, סוגי מדיה, עריכה ומחיקה |
| `lib/chat/stats.ts` | `computeStats()` – כל המדדים מהטבלה: נתח, פותחי שיחה (3 שעות), זמן תגובה (חציון עד 6 שעות), בוקר טוב, שבת, יום שיא, רצף ושתיקה, שעות, צחוק, מילים, אימוג'י, הודעות קוליות |
| `lib/chat/compress.ts` | פורמט דחוס ל-LLM (`חותמת\|שם\|טקסט`, `[תמונה ×3]`), חיתוך מהסוף לפי תקציב טוקנים |
| `lib/setup.ts` | 8 שאלות האיפיון, ב-3 משפחות UI: Tiles, Chips, Slider |
| `lib/brand.ts`, `components/receipt.tsx` | שם המוצר ורכיבי הקבלה (שורה עם נקודות, קו חיתוך, נייר) |
| `components/StatsReceipt.tsx` | הקבלה המפורטת (7 פריטי המספרים) |
| `lib/report/*` | פרומפט הפרסונה, סכמת JSON, קריאה ל-Claude, אימות ציטוטים, חיתוך ה-paywall |
| `app/setup` | 8 השאלות כשיחה (הפענוח קורה בדפדפן) |
| `app/c/[id]` | הדפסה ← קבלה מפורטת ← "מחשב את השורה התחתונה" ← קבלה עם paywall |
| `app/r/[token]` | קישור שיתוף ארוך ואקראי, הכותרת משמשת כ-`<title>` וכ-OG |
| `app/api/cron/cleanup` | מחיקה אחרי 48 שעות בלי רכישה, ומחיקת ההודעות 7 ימים אחרי הדוח (הדוח נשאר לשיתוף) |

## לפני production

- `lib/server/store.ts` שומר לקבצים ב-`.data/`. ב-Vercel מערכת הקבצים זמנית, אז צריך להחליף ל-Supabase (Postgres + Storage). הממשק קטן.
- OTP: לחבר שליחת מייל אמיתית (Supabase Auth או Resend) ב-`app/api/otp/route.ts`.
- Stripe: אימות התשלום קורה בחזרה מ-Checkout. כדאי להוסיף גם webhook של `checkout.session.completed`.
- יצירת הדוח רצה בתוך הבקשה (`maxDuration = 300`). בעומס כדאי להעביר לתור.
